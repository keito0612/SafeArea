# SafeArea

## 概要

| 項目 | 内容 |
|------|------|
| アプリ名 | SafeArea |
| コンセプト | 引っ越し前に災害リスクがわかる地図サービス |
| ターゲット | 引っ越し検討者、物件購入検討者 |
| 対象地域 | 全国 |
| プラットフォーム | Webアプリ |

## セットアップ

### 必要なもの

- Docker / Docker Compose

### クイックスタート

```bash
# リポジトリをクローン
git clone https://github.com/isobekeito/safearea.git
cd safearea

# 全サービスを起動（DB + バックエンド + フロントエンド）
docker-compose up -d

# アクセス
# - フロントエンド: http://localhost:3000
# - バックエンドAPI: http://localhost:8080
# - データベース: localhost:5432
```

### 開発コマンド

```bash
# 全サービス起動
docker-compose up -d

# ログを確認
docker-compose logs -f

# 特定サービスのログを確認
docker-compose logs -f frontend
docker-compose logs -f backend

# サービス停止
docker-compose down

# サービス再ビルド（Dockerfile変更時）
docker-compose up -d --build

# DBのみ起動
docker-compose up -d db
```

### 個別起動（Docker不使用）

```bash
# フロントエンド
cd frontend
npm install
npm run dev

# バックエンド
cd backend
go run cmd/api/main.go
```

## 背景・課題

### 解決したい課題

引っ越し・物件購入を検討する人が直面する問題：

1. **ハザードマップが見にくい**
   - 自治体ごとにバラバラ
   - PDFで比較しにくい

2. **複数の災害リスクを一括で確認できない**
   - 洪水、地震、土砂災害など別々に調べる必要がある

3. **過去の災害履歴がわからない**
   - 実際にその地域で何が起きたのか知りたい

### SafeAreaの解決策

```
1. 住所を入力するだけ
   → 5種類の災害リスクを一括表示

2. 総合評価でわかりやすく
   → 🔴🟡🟢 の3段階で一目でわかる

3. 過去の災害も確認できる
   → 実際に起きた災害の記事・リンクを表示
```

## 災害リスク種別

| # | 種別 | データソース | 表示 |
|---|------|--------------|------|
| 1 | 洪水浸水 | ハザードマップポータル | 高/中/低 |
| 2 | 土砂災害 | ハザードマップポータル | 高/中/低/対象外 |
| 3 | 地震危険度 | 地震調査研究推進本部 | 高/中/低 |
| 4 | 津波浸水 | ハザードマップポータル | 高/中/低/対象外 |
| 5 | 液状化 | J-SHIS + 自治体 | 高/中/低/データなし |

## タグ一覧

| タグ | 条件 |
|------|------|
| 🌊 水害注意 | 洪水浸水リスク「中」以上 |
| 🏔️ 土砂注意 | 土砂災害警戒区域内 |
| 🌏 地震注意 | 地震危険度「高」 |
| 🌊 津波注意 | 津波浸水想定区域内 |
| 💧 液状化注意 | 液状化リスク「中」以上 |
| ⚠️ 被害歴あり | 過去に災害記録あり |

## 総合評価ロジック

| 評価 | 条件 |
|------|------|
| 🔴 要注意 | 高リスクが2つ以上 or 被害歴あり |
| 🟡 注意 | 高リスクが1つ or 中リスクが2つ以上 |
| 🟢 比較的安全 | 高・中リスクが少ない |

## データソース

| データ | ソース | 取得方法 | 更新頻度 |
|--------|--------|----------|----------|
| 洪水・土砂・津波 | 国土交通省ハザードマップポータル | 地図タイル | リアルタイム |
| 地震危険度 | 地震調査研究推進本部 | CSV → DB格納 | 年1回 |
| 液状化 | J-SHIS | API | リアルタイム |
| 過去の災害（50年分） | 内閣府・気象庁 | 初期データとしてDB登録 | 年1回更新 |
| 住所→緯度経度 | 国土地理院 | API | リアルタイム |

### データソースURL

- ハザードマップポータル: https://disaportal.gsi.go.jp/
- J-SHIS: https://www.j-shis.bosai.go.jp/
- 地震調査研究推進本部: https://www.jishin.go.jp/evaluation/seismic_hazard_map/

### データベース設計（PostgreSQL）

#### disasters（過去の災害データ）※過去50年分

| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| type | VARCHAR(20) | 災害種別（earthquake/typhoon/flood/landslide/tsunami/other） |
| name | VARCHAR(255) | 災害名 |
| year | INTEGER | 発生年 |
| damage | TEXT | 被害内容 |
| prefecture_code | VARCHAR(2) | 都道府県コード |
| city_name | VARCHAR(255) | 市区町村名（任意） |
| created_at | TIMESTAMP | 作成日時 |

#### disaster_areas（災害の被災地域）

| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| disaster_id | UUID | FK → disasters |
| city_name | VARCHAR(255) | 市区町村名 |
| damage_summary | TEXT | 被害概要 |

#### earthquake_risks（地震危険度データ）

| カラム | 型 | 説明 |
|--------|-----|------|
| mesh_code | VARCHAR(20) | PK（メッシュコード） |
| risk_level | VARCHAR(10) | high/medium/low |
| probability | DECIMAL(5,2) | 30年以内の発生確率 |
| updated_at | TIMESTAMP | 更新日時 |

### Lambda + RDS 接続の注意点

| 課題 | 対策 |
|------|------|
| コネクション枯渇 | Lambda同時実行数を制限（10〜50） |
| VPC内のコールドスタート | Provisioned Concurrencyは高いので使わない |
| 将来的なスケール | RDS Proxyを導入（月$10〜追加） |
